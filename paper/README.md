# TreeWork Paper Draft

This directory contains the arXiv-style system and methodology paper for
TreeWork.

## Build

```bash
make
```

The generated paper is `main.pdf`.

The Mermaid source for the composable state-memory concept figure is available
at `assets/composable-state-memory.mmd`; the paper renders the same architecture
with TikZ.

## Current Draft Boundary

- The Introduction, related work, formal problem statement, methodology,
  conditional continuation guarantees, and implemented-system description are
  written.
- The evaluation section defines a reproducible protocol for a future
  controlled empirical study.
- Confirm title and release status before uploading to arXiv.
